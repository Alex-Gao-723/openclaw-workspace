# 视频笔记助手

在 B站、YouTube 等视频网站，按 **⌘+Shift+S**（Mac）截图，DeepSeek AI 自动分析画面内容，追加到 Markdown 格式的笔记中。

---

## 功能

- **快捷键截图**：`⌘+Shift+S`（Mac）/ `Alt+S`（Windows），截取当前视频画面
- **AI 自动分析**：截图压缩后发送给 DeepSeek，提取画面中的关键信息、文字、公式、代码等
- **自动记录时间戳**：每条截图笔记附带视频播放时间（如 `08:42`）
- **Markdown 笔记**：同一视频的截图自动归入同一篇笔记，格式整洁可导出
- **笔记管理**：查看、编辑、搜索、删除笔记，一键导出 `.md` 文件
- **全屏可见通知**：截图和 AI 分析结果 Toast 提示，全屏模式下同样可见
- **多截图不冲突**：AI 分析任务串行队列处理，连续截图时各自分析互不覆盖

## 安装

### 第一步：加载 Chrome 扩展

1. 打开 Chrome，地址栏输入 `chrome://extensions/` 回车
2. 右上角开启「**开发者模式**」
3. 点击「**加载已解压的扩展程序**」
4. 选择项目根目录（含 `manifest.json` 的文件夹）
5. 工具栏出现扩展图标，安装完成

### 第二步：获取 DeepSeek API Key

前往 [DeepSeek Platform](https://platform.deepseek.com/api_keys) 注册并创建 API Key。

### 第三步：配置 API Key

1. 点击工具栏扩展图标 → 右上角 **⚙ 设置**
2. 粘贴 API Key → 点击「**保存设置**」
3. 点击「**测试连接**」，提示「✅ API 连接成功」即完成

> 扩展代码更新后，在 `chrome://extensions/` 点击 🔄 刷新，再刷新视频页面即可生效。

## 使用方法

### 截图记录

1. 打开 B站、YouTube 或任意有视频的页面，播放视频
2. 看到想记录的内容时，按 **`⌘+Shift+S`**（Mac）或 **`Alt+S`**（Windows）
3. 右下角依次出现两条提示：
   - `✅ 截图已保存，AI 分析中...` — 截图成功
   - `🤖 AI 分析完成` — 笔记已更新
4. 全屏模式下提示同样可见

### 查看笔记

点击工具栏扩展图标，打开笔记弹窗：

- **左侧**：笔记列表，按最近更新排序，显示截图数量
- **右侧**：笔记内容，含截图预览和 AI 分析文字

### 搜索笔记

左侧顶部搜索框输入关键词，实时过滤（支持标题和内容）。

### 编辑笔记

点击右上角「**✏️ 编辑**」进入编辑模式，直接修改 Markdown 内容。
`⌘+S` / `Ctrl+S` 保存，`Esc` 取消。

### 新建笔记

点击「**＋ 新建**」，填写标题和视频链接（可选），创建空白笔记手动编辑。

### 导出笔记

点击「**⬇ 导出**」，将当前笔记（含 base64 截图）保存为本地 `.md` 文件，可用 Obsidian、Typora 等工具打开。

### 删除笔记

点击「**🗑**」→ 确认，删除笔记及所有关联截图（不可恢复）。

## 笔记格式示例

```markdown
# Vue3 响应式原理深度解析

**来源**: [https://www.bilibili.com/video/BV1xx...](...)

---

## 截图 `08:42` — 2026/5/6 14:30:00

![截图](screenshot://ss_1234567)

**AI 分析**：

> 截图展示了 Vue3 响应式系统核心原理图。左侧为 Proxy 拦截层，
> 右侧为 Effect 依赖追踪机制。track() 负责依赖收集，trigger()
> 负责变更通知，两者配合实现数据响应式更新。

**我的笔记**：

（在这里补充自己的理解）
```

## 设置项

| 项目          | 说明                         |
| ------------- | ---------------------------- |
| API Key       | DeepSeek 密钥，必填          |
| AI 模型       | `deepseek-v4-pro`（默认）  |
| AI 分析提示词 | 自定义分析指令，留空使用默认 |

**自定义提示词示例：**

```
# 代码教程
请提取截图中的代码片段，说明其功能和关键语法点。

# 英语学习
请提取截图中的英文内容，翻译成中文并列出重点词汇。

# PPT / 演讲
请将截图中的文字要点整理为简洁的条目列表。
```

## 技术说明

| 模块        | 技术                                                 |
| ----------- | ---------------------------------------------------- |
| 截图        | `chrome.tabs.captureVisibleTab`（JPEG 85%）        |
| AI 图片传参 | 截图先压缩至 800px / JPEG 65%，嵌入文本发送          |
| 多截图并发  | 串行队列 + 唯一占位符 TAG，各截图分析互不干扰        |
| 全屏通知    | Popover API top layer，高于全屏层                    |
| 数据存储    | 浏览器本地 IndexedDB，不上传任何数据                 |
| AI 调用     | DeepSeek `/v1/chat/completions`（OpenAI 兼容格式） |

---

## 数据与隐私

- 笔记和截图全部存储在**本地 IndexedDB**，不同步到任何服务器
- 截图仅在分析时发送给 DeepSeek API，分析完成后不再传输
- 「设置 → 清除所有数据」可删除全部本地数据
